# Personalized Course Eligibility Checker

## Project Description

The Personalized Course Eligibility Checker is a web-based application
developed using HTML, CSS, and JavaScript.

It checks whether a student is eligible for a course based on:
- Age
- Attendance Percentage
- JavaScript Test Mark

## Features

1. Student registration form
2. Input validation
3. Roll number validation using Regular Expression
4. Personalized eligibility checking
5. Three eligibility levels:
   - Eligible
   - Improvement Required
   - Not Eligible
6. Preferred learning topics displayed dynamically
7. DOM manipulation using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Regular Expressions
- DOM Manipulation

## Eligibility Criteria

### Eligible
- Age >= 18
- Attendance >= 75%
- JavaScript Test Mark >= 60

### Improvement Required
- Attendance >= 60%
- JavaScript Test Mark >= 40

### Not Eligible
- Does not satisfy the above conditions

## Roll Number Format

The Roll Number should follow this format:

ITB07

Example:

ITB01
ITB02
ITB07

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter student details.
5. Click "Check Eligibility".
